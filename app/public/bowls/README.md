# Bowl photos

Drop the bowl photos in this folder with these exact filenames:

- `basic-bitch.jpg` — the Basic Bitch bowl
- `paradise-bowl.jpg` — The Paradise Bowl

The menu page picks them up automatically (see `photo` in `src/bowls.js`).
Until a file exists, the site shows the text placeholder instead.
Square-ish, top-down shots crop best in the round frame.
